我从 2019 年开始写博客，最初只是想记录学习笔记。后来发现，写下来才是真的学会了。

现在这里主要写三类内容：**前端工程笔记**（架构、性能、踩坑）、**工具流分享**（写作、笔记、效率工具的实战评测），以及偶尔的**个人随笔**。

我不喜欢追热点，所以更新频率不算高。基本上每个月写 2–4 篇，每篇都会反复改到自己满意为止。如果你也喜欢这种节奏，欢迎订阅 Newsletter。

## 关于这个博客

技术栈：

- **静态生成**：自建构建流程（万级文章秒级构建）
- **主题**：视觉层完全自写，不依赖任何现成模板
- **排版**：Source Serif 4（标题）+ Inter（正文）+ JetBrains Mono（代码）
- **部署**：任意静态托管（Vercel / Cloudflare Pages / Netlify / GitHub Pages 都行）
